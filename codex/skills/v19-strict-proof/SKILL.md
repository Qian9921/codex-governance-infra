# V21 Strict Proof (stable ID: v19-strict-proof)

## Acceptance lock

Freeze the exact objective, owner, reference version, configuration, domain,
data identity, metric, tolerance, invariants, non-goals, rollback, snapshot,
denominator, usage budget, and stop conditions before implementation. Missing
authority, an essential oracle, privacy clearance, or budget blocks only the
dependent claim.

## Bind the current intake once

The `UserPromptSubmit` hook supplies current task, shape, and intake SHA-256
values. Record exactly one contract with the applicable scope and route flags:

```bash
rtk python3 "${CODEX_HOME:-$HOME/.codex}/bin/toolchain-auto.py" \
  --record-task-contract \
  --repository-work \
  --task-id-sha256 <task-sha256> \
  --task-shape-sha256 <shape-sha256> \
  --intake-id-sha256 <intake-sha256> \
  <only-applicable-route-flags>
```

Use `--non-repository-task` instead of `--repository-work` when appropriate;
do not run repository preflight for a strict non-repository task. Available
route flags are:

```text
--unknown-semantic-entrypoint
--similar-implementation
--known-symbol-or-call
--dependency-or-blast-radius
--exact-text-error-config-log
--shell-output-for-model
--machine-exact-only
```

## Execute and review

1. Use the retained V16 FAST/CANDIDATE/FINAL evidence and enforcement contracts.
   Preserve the explicit `--strict-maintenance` one-attempt V16 controller; its
   exhaustion opens that strategy's circuit, not the whole recovery mission.
2. Freeze Semble and CodeGraph repository, HEAD/tree, worktree, index, query,
   artifact, and receipt identities before using them as cognitive evidence.
3. Require exact denominators and reject missing/skipped cases, NaN/Inf, stale
   identity, or an absent oracle. Exact zero difference is required only when
   the acceptance lock says so.
4. Use a fresh read-only `sol_reviewer`. For R2+, the reviewer inspects source,
   contract, tests, and at least one source-derived counterexample. Bind the
   verdict to the exact head/tree; stable fixes are delta-only.

Do not downgrade the profile to avoid a real blocker and do not broaden the
frozen target merely to add ceremony.
